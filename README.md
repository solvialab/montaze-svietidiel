# Flash of Light — statická webstránka

Toto je obyčajná statická stránka. Nepotrebuje Node.js, npm ani build.

## Najjednoduchšie spustenie

Dvojklikom otvor `index.html` v prehliadači.

## Odporúčaný lokálny náhľad

Ak máš Python, v tomto priečinku spusti:

```powershell
python -m http.server 8080
```

Potom otvor `http://localhost:8080`.

## Súbory

- `index.html` — obsah stránky
- `styles.css` — dizajn, responzivita a animácie
- `script.js` — scroll animácie, mobilné menu a 3D pohyb
- `assets/` — fotografie, video, favicon a social-preview obrázok

Na bežný hosting stačí nahrať tieto tri súbory a celý priečinok `assets`.
